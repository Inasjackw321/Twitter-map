🗺️ Twitter Conflict Map Generator

Interactive geolocation mapping for geopolitical conflicts

🚀 Quick Start

How to Generate Maps:

  1. Open your terminal/command prompt
  2. Run setup (first time only): ./setup.sh
  3. Add your Twitter API credentials to .env file
  4. Generate a map: python main.py ukraine_russia
  5. Refresh this page and click "View Map" below!

💻 Command Reference

Common Commands:

  • ./setup.sh - Initial setup and install dependencies
  • python main.py ukraine_russia - Generate Ukraine-Russia map
  • python main.py israel_iran --max-tweets 100 - Collect 100 tweets
  • python main.py china_taiwan --no-heatmap - Disable heatmap layer
  • ./run_all.sh - Generate all 4 maps at once
